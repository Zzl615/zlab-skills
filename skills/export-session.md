# export-session

请把当前 session 整理为 markdown，按“用户提问 → AI回答 → 执行操作”的顺序输出。

输出要求：

# Session Title

用一句话概括本次会话主题。

# Timeline

按时间顺序整理，每一轮都使用下面格式：

## Round 1

### 用户

记录这一轮用户的问题或要求。

### AI

记录这一轮 AI 给出的回答、分析、建议或方案。

### 执行

记录这一轮实际发生的操作，例如：

* shell 命令
* 配置修改
* 文件改动
* 代码示例
* SQL / curl / jq / git 命令
* 如果这一轮没有实际执行，写“无”

### 结果

记录这一轮执行后的结果、现象、报错、输出或结论。
如果没有明确结果，写“待验证”。

## Round 2

### 用户

### AI

...

### 执行

### 结果

# Final Conclusion

最后单独输出一份总结，包含：

## 问题本质

一句话说明本次问题的核心。

## 关键结论

列出最终确认的结论。

## 最终方案

给出最终采用或推荐的做法。

## 后续动作

列出接下来建议执行的事项。

整理要求：

* 保持一问一答一执行，不要把不同轮次混在一起
* 删除重复表述，保留有效信息
* shell、SQL、curl、git、配置片段用代码块展示
* 最终输出必须是可直接保存的 markdown
* 若某一轮没有执行操作，明确写“无”
* 若有报错信息，尽量保留原始关键信息
